# Datheon Python Internship Projects

## About the Project
This repository contains two Python projects developed as part of the **Datheon Python Programming Internship**.

The projects demonstrate Python programming, file handling, automation, problem-solving, and user interaction.

## Task 1: Hangman Word Guessing Game

A console-based word guessing game developed using Python.

### Features
- Random word selection from an English word list.
- Six incorrect guessing attempts.
- Hangman ASCII art.
- Tracks previously guessed letters.
- Displays winning and losing messages.
- Option to play again.

### How to Run
```bash
python hangman.py
```

**Required file:** `google-10000-english-no-swears.txt`

## Task 3: Automated File Organizer & Cleanup Utility

A Python automation tool that organizes files into different folders based on their extensions.

### Features
- Scans files in a selected directory.
- Categorizes documents, images, videos, archives, and code files.
- Automatically creates category folders.
- Moves files using Python's `shutil` module.
- Handles duplicate filenames and file errors.
- Displays an execution summary.

### How to Run
```bash
python organizer.py
```

Enter the folder path when prompted and confirm the operation. Test using a folder containing copies of files.
